The silhouette coefficient \(s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}\) measures within-cluster compactness \(a(i)\) vs nearest-neighbor cluster separation \(b(i)\). Peak at \(K=4\) confirms optimal partitions.

DBSCAN & Linkages Hierarchical & Density-Based Clustering

Beyond spherical centroid assumptions:

Agglomerative Hierarchical Linkages:
  • Ward Linkage: Minimizes total within-cluster variance (best for compact groups)
  • Complete Linkage: Max distance between elements (compact spherical clusters)
  • Single Linkage: Min distance (prone to chaining effect)
DBSCAN Density-Based Properties:
  • Hyperparameters \(\epsilon\) (neighborhood radius) and \(\text{minPts}\) (core density threshold)
  • Naturally handles non-convex, manifold cluster shapes
  • Outliers identified natively as noise points without forcing into a cluster
Downstream Pipeline Practical ML Pipeline: Unsupervised Labels as Supervised Features

Industrial architecture bridging unsupervised discovery with downstream supervised inference:

Feature Augmentation Pattern:

Unsupervised cluster IDs (0, 1, 2, 3) are encoded as one-hot indicators and fed into downstream supervised gradient boosted models. This explicitly captures non-linear cohort topology that raw linear features miss.

Isolation Forest Anomaly Detection:

Student profiles with inconsistent attributes (e.g., 9.8 CGPA but 10% coding score) require fewer random partition cuts to isolate. The tree isolation depth directly yields anomaly scores without supervision.
